Partial Lunar Eclipse（月偏食）是 Kimi Code 的 Tauri 桌面客户端——同一个 daemon、同一套会话与工具链，换上原生桌面外壳。 月，是 Kimi / Moonshot；偏食，是衍生而不遮蔽。

特性

同一枚月亮的两种光：Kimi 的蓝与偏食的铜。

💬

QQ 式双列聊天

用户与 agent 分侧气泡，markdown 以气泡自身墨色融合渲染——代码块、链接、引用、表格，在七套主题下都浑然一体。

🧩

类型化工具卡

思考 / 工具 / MCP / JSON / 终端 / 审批 / 提问各就其位；文件卡显示工作区相对路径，Bash 卡显示命令概略，扫一眼就懂。

🌗

插件市场

服务端代理注册表 + 「发现」页，官方 / 精选 / 社区分层；版本更新一次性提醒，计费插件安装时给出配额提示。

🪪

账号与配额可见

绑定卡显示登录账号 ID，周/短周期配额实时条与重置倒计时——会员权益看得见。

📦

诊断包导出

会话头部一键导出诊断归档，服务端自动打包脱敏后的桌面端日志，排障不靠猜。

🔒

私有内嵌 daemon

隔离的 KIMI_CODE_HOME、随机回环端口，随应用启停；浏览器 UI 为可选挂载，无资产时仅以 REST/WS 运行。

🎨

七套主题

dark / light / clay / neon / glass / aqua / system，同一套设计变量驱动，切换无闪烁。

⚡

性能精修

流式渲染全链路调优：turns 记忆化、markdown 解析节流、事件按帧合流——长会话与高速 token 流下依旧顺滑。

与上游

衍生而不遮蔽——持续合并 MoonshotAI/kimi-code 主干。

聚焦

仅保留 Tauri 桌面路线：移除浏览器版（apps/kimi-web）与 Electron 包装版，daemon 的浏览器 UI 改为可选挂载，无资产时 API-only 启动

渲染

聊天体系重做：双列气泡 + 墨色融合 + 类型化卡片 + 技能/插件命令卡片化

服务端

插件市场注册表代理 + 管理 REST、智能体档案目录、会话 cron 管理、/oauth/account 账号身份

诊断

会话导出打通桌面端日志：渲染进程日志脱敏落盘，导出时由服务端打包

同步

持续合并上游 main（引擎重构、WS 即时冲刷、遥测、secondary_model 配置等）并保持客户端对齐

快速开始

需要 Node ≥ 24.15、pnpm 10.33 与 Rust 工具链。

git clone https://github.com/d2rabbit/kimi-code.git
cd kimi-code
pnpm install
pnpm --filter @moonshot-ai/kimi-desktop-tauri run tauri:dev

打包安装包：bash apps/kimi-desktop-tauri/scripts/build-run.sh --dist（或推 desktop-v* 标签走 Actions 四平台构建）
