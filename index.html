特性

从渲染层到系统层，围绕桌面体验重做了一遍。

💬

类型化聊天卡片

思考、工具调用、MCP、JSON、终端、审批、提问——每种内容都有专属的渲染身份与交互，不再挤在同一副面孔里。

🧩

插件市场

服务端代理注册表 + 「发现」页浏览安装；版本更新一次性提醒，计费插件安装时给出配额提示。

🪪

智能体档案目录

实时档案目录展示可用智能体，内置 delegate 委派入口，子智能体任务一目了然。

⏰

会话定时任务

cron 管理 REST 接口 + 设置面板，让会话按节奏自动运转。

📦

诊断包导出

会话头部一键导出诊断归档，服务端自动打包桌面端日志（脱敏、限量、滚动），排障不再靠猜。

🎨

七套主题

dark / light / clay / neon / glass / aqua / system，同一套设计变量驱动，切换无闪烁。

🪟

原生窗口体验

窗口控制按钮遵循各操作系统惯例，标题栏、徽章计数等细节按平台适配。

🔒

私有内嵌守护进程

应用自带 daemon：隔离的 KIMI_CODE_HOME、随机回环端口，随应用启动、随应用退出，绝不串扰共享实例。

与上游的差异

本仓库是 kimi-code 的 fork，在跟踪上游 main 的同时，沉淀了以下增量能力。

客户端

全新 Tauri 2 + Svelte 5 桌面客户端，与 Electron 包装版平行，直连同一 daemon（REST + WebSocket）

渲染

聊天卡片身份体系重做：think / tool / mcp / json / terminal / approval / question 分类渲染

服务端

插件市场注册表服务端代理 + 管理 REST；智能体档案只读目录接口；会话 cron 管理接口

诊断

会话导出打通桌面端日志：渲染进程日志脱敏落盘，导出时由服务端打包

同步

持续合并上游 main（引擎重构、WS 即时冲刷、遥测、secondary_model 配置等）并保持客户端对齐

快速开始

需要 Node ≥ 24.15、pnpm 10.33 与 Rust 工具链。

git clone https://github.com/d2rabbit/kimi-code.git
cd kimi-code
pnpm install
pnpm --filter @moonshot-ai/kimi-desktop-tauri run tauri:dev

打包发行版：pnpm --filter @moonshot-ai/kimi-desktop-tauri run tauri:build
