03 · RELEASE NOTES

每一次偏食，
都记得光从哪里补进来。

每个版本都写清两件事：从上游 MoonshotAI/kimi-code 同步了什么，以及合并进桌面端的改动有哪些。

2026-08-05 最新 上游 0.33.0

同步上游0.31.1 → 0.33.0

  • CLI 各界面（TUI、kimi -p、kimi acp 等）默认运行在 agent-core-v2 引擎，KIMI_CODE_LEGACY_FLAG=1 可回退（0.33.0）。
  • /plugins 市场新增 Kimi Computer Use 与 Kimi WebBridge 官方内置能力，安装自动配置托管运行时、中断可重试；合作伙伴页更名 Curated（0.33.0）。
  • 新增 TurnStarted、UserPromptQueued、TaskStarted、SessionHeartbeat 四个 hook 事件，hook 负载带上会话标题与客户端类型（0.32.0）。
  • 新增 [token_counting] 配置节；[loop_control] 两个配置键改名并有启动改名警告（0.32.0）。
  • MCP：OAuth 重新授权失效自动重注册、首请求等待初始化完成、structuredContent 与 _meta 透传给模型（0.32.0 / 0.33.0）。
  • 新增 /bug 作为 /feedback 别名；启动询问是否信任当前文件夹；/fork 不再切换会话；交互式 TUI 启动不再立即建会话（0.33.0）。
  • 新增实验性 ACP server（kimi acp-v2），问题经 elicitation 桥接并支持宿主斜杠命令（0.32.0）。

合并进桌面

  • 内嵌 daemon 全量重建，上述引擎、MCP、hook 与协议能力自动继承；/meta 实验标志等新增字段完成兼容性核对。
  • 斜杠菜单补齐 /feedback、/bug、/secondary_model、/effort（上游 /thinking 新名，带参直接设置思考级别）；修复菜单描述长期显示 i18n 键原文的问题，补齐中英全部命令文案。
  • kap-server 插件市场 API 注入 Computer Use / WebBridge 内置能力行，桌面插件面板可直接浏览安装；已装插件的信任标识改为按官方目录 tier 判定，kimi-datasource 正确显示「官方」。
  • 应用更名为 Partial Lunar Eclipse，启用原创月偏食图标（全套平台图标 + 站点 favicon）。
  • 修复打包安装后内嵌 agent 启动即退出：无 package.json 的布局下 web 资产解析直接崩溃，现按 API-only 正常启动。
2026-08-01 上游 0.31.1

同步上游0.29.2 → 0.31.1

  • 插件可贡献自定义子代理与 systemPrompt 指令，新增 /secondary_model 辅助模型命令（0.31.0）。
  • TaskOutput 改为即时快照，查询后台任务不再阻塞会话（0.31.0）。
  • 修复模型目录瞬时清空导致的 “model is not configured”；Esc 中断保留已输出内容；减少 TUI 频繁全屏重绘（0.31.1）。
  • web 侧：Monaco 代码高亮、权限模式按安全度排序、草稿会话可用的 @ 文件提及、暗色单色 composer 修复（0.31.1）。
  • 公共模型目录不可达时回退到内置快照，离线或被阻断网络下也能导入第三方 Provider。

合并进桌面

  • 上述引擎、协议与 CLI/SDK 能力全量进入 Tauri 客户端，按原生桌面边界适配。
  • 恢复 AGENTS.md 的桌面项目条目与 flake.nix 漂移说明，修正指向已删除 Electron 应用的 dev 脚本。
  • oxlint 全仓清零 error 级诊断（eqeqeq、floating promises、冗余联合类型等 14 处）。
